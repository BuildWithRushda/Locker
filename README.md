Locker 🔒

Take control of every recurring payment before it controls you.

Locker is a UPI-native subscription and autopay manager — track spending, catch silent renewals, and stay ahead of every auto-debit, all in one clean dashboard.

🔗Live: moneylocker.netlify.app

---

## ✨ Features

- 📊 **Subscription Calculator** — instantly see your total recurring spend
- 📚 **Interactive App Library** — browse 34+ popular subscription apps
- 🆓 **Free Tier** — core features available with no signup required
- 📩 **Early Access Waitlist** — join to get notified at launch

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- LocalStorage for client-side state
- Formspree for waitlist integration
- Deployed on Netlify

## 🚀 Getting Started

Clone the repo and open `index.html` in your browser — no build step required:

```bash
git clone https://github.com/your-username/locker.git
cd locker
open index.html
```
